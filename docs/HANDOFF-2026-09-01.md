## 6. 验证清单 (给下一个开发者)

### 6.1 启动环境
```bash
# 1. 启动基础设施
./deploy/up.sh

# 2. 验证
bash e2e-test.sh            # 6/6 业务断言 PASS
./deploy/up.sh --check     # 0 配置漂移
```

### 6.2 业务服务
```bash
mvn -pl cloud-infra-gateway spring-boot:run
mvn -pl cloud-infra-auth spring-boot:run
mvn -pl cloud-infra-modules/system-module spring-boot:run
```

### 6.3 codegen 端到端
```bash
cd cloud-infra-codegen/cloud-infra-codegen-core
mvn dependency:build-classpath -Dmdep.outputFile=/tmp/cp.txt -q
CP=$(cat /tmp/cp.txt):target/test-classes:target/classes
java -cp "$CP" com.cloudinfra.codegen.FlywayGenerateDemo \
  /path/to/V1__init_schema.sql /tmp/codegen-output system
# 输出: 15 张表全套代码
```

### 6.4 业务告警
```bash
# Counter 注册与抓取
curl http://localhost:9301/management/prometheus | grep auth_login_attempts
# 期望: auth_login_attempts_total{result="failure"} N
```

### 6.5 测试
```bash
mvn clean test            # 101 tests
mvn test -pl cloud-infra-codegen/cloud-infra-codegen-core  # 25 codegen
```
