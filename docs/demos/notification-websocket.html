🔔 Cloud-Infra Notification WebSocket Demo

使用说明:
1. M7-03 后 WS 握手需内部签名头（X-Internal-Call/Timestamp/Nonce）+ X-User-Id，浏览器原生 WebSocket 无法直接设置自定义头；请使用 docs/demos/notification-websocket-e2e.py 或经网关/代理注入头后连接
2. 端点: ws://localhost:8084/notification/ws（无 userId 路径参数）
3. 连接后可通过 POST /notification/send 触发推送验证
