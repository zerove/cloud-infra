### 🛠️ Caffeine ClassLoader 死锁修复 (commit `ef0d69d`)

**问题**: Spring Boot 4.1.0 + Caffeine 3.x + JDK 25 ClassLoader 在 512m heap 下循环触发死锁, system 启动 90 秒后 exit(1).

**修复** (deploy/compose.yaml):
- `cloud-system mem_limit`: 768m → **2g**
- JAVA_OPTS: `-Xmx512m -Xms256m` → **`-Xmx1536m -Xms512m`**
- 追加 `--enable-native-access=ALL-UNNAMED` (JDK 25 Restricted methods 警告消除)

**实测**: system 86.19 秒启动成功, healthcheck 12 component 全 UP, virtualThreadMonitor liveThreadCount=121.

### 📊 业务告警指标 AOP 化 (commit `8430811`)

**问题**: 11 条 Prometheus 告警规则中, 2 条业务类指标 (`auth_login_attempts_total` + `file_upload_failures_total`) 业务代码从未实现 (0 处 Micrometer Counter 用法).

**解决方案**:
- 新增 `@BusinessMetric` 注解 (cloud-infra-framework/framework-web)
- 新增 `BusinessMetricAspect` AOP 切面 (用 @Around + @AfterThrowing, 避免 try-catch, 合规 adg `java-catch-all` 规则)
- Counter 按 (metric, tag) 缓存, 按需注册
- 业务模块接入:
  - `auth/SysLoginService.login()` → `@BusinessMetric(metric="auth.login.attempts", resultOnSuccess="success", resultOnFailure="failure")`
  - `file/FileServiceImpl.upload()` → `@BusinessMetric(metric="file.upload.failures", reason="upload")`

**对应告警** (真正可触发):
- `LoginFailureRateHigh` (cloud-infra-alerts.yml:115): `auth_login_attempts_total{result=failure} / total > 0.5` 持续 3m
- `FileUploadFailureHigh` (line 124): `file_upload_failures_total{} > 0.1/s` 持续 5m

**单元测试**: `BusinessMetricAspectTest` 8 tests, 0 fail (覆盖 Counter 创建 / 复用 / Result 智能判断 / 异常传播).
