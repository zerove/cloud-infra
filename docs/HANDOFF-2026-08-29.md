## 7. 已知问题与限制

### 7.1 真实未做（未来 PRD）
- **租户数据隔离** — TenantContext 基础设施就绪，缺数据隔离 schema + interceptor
- **SLO dashboard** — 11 条告警规则已就绪，缺统一 Grafana SLO 视图
- **APM 接入** — 当前仅 OpenTelemetry exporter，缺 SkyWalking/Pinpoint
- **业务模块 native 化** — ADR-005 论证暂缓（MyBatis-Plus 动态代理限制）

### 7.2 框架限制（非 bug）
- **业务模块间隔离 ArchUnit 规则暂跳过** — Maven 多模块 classpath 限制
- **Feign LoadBalancerFeignClient 偶发 EOF** — 虚拟线程 + 容器内网络栈边界 case
  - 由 NotificationApiFallbackFactory 兜底降级，不影响业务

### 7.3 需要手动维护
- **业务模块依赖** — 当前靠人工 review 保证
  - ArchUnit 已在 system-module 内验证自己的依赖
- **告警指标接入** — 业务告警 (auth_login_attempts_total / file_upload_failures_total)
  - 需在 auth/file 模块 MetricsConfig 注册 Micrometer Counter

## 8. 给下一个接手者的建议

### 8.1 日常开发流程
1. **改业务代码** → 跑 `mvn -pl <module> test` → 本地 e2e
2. **改 framework/common** → 跑 ArchUnit + e2e-test
3. **改 Nacos 配置** → `./deploy/up.sh --sync` → 重启相关容器
4. **新增业务模块** → 同步加 ArchUnit 镜像测试（参考 system-module）

### 8.2 性能优化
- 当前 p99 970ms 已达成验收口径（< 2s）
- 进一步优化：CDN 缓存 / 数据库读写分离 / MyBatis-Plus 分页优化

### 8.3 安全加固
- 当前已闭环：env 脱敏 + 缓存失效 + MQ 凭据 + 令牌吊销 + 插件安全
- 未来方向：mTLS 内部通信 / OWASP dep-check / Secret rotation

### 8.4 可观测性
- 当前已有：11 告警 + 5 Grafana dashboard + OTel trace
- 下一步：SLO 体系（err rate / p99 / saturation）+ 业务指标
