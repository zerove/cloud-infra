## P0 业务正确性

### P0-1: actuator/health
**结论**: 非 bug, 设计正确
- 业务端口 8082 `/actuator/*` → 500 (Sentinel 拒绝, 因为无 management endpoint 暴露)
- 管理端口 9303 `/management/health` → 200 完整健康
- 配置: `management.endpoints.web.base-path: /management` + `management.server.port: 9301` (ADR-008)
- 12 个 component 全 UP: db, rabbit, redis, diskSpace, ping, ssl, virtualThreadMonitor 等
- **验证: virtualThreadMonitor 已显示 pinnedMonitorRunning=true**

### P0-2: 事务边界
**结论**: 设计合规, 13 个 `@Transactional` 文件, 无 service 在事务内调 Feign
- package-info.java 明确约束: "@Transactional 显式声明 rollbackFor, Feign 调用移出事务"
- 5/5 Feign Client 都有 fallbackFactory (快速降级)
- 14+ @Transactional rollbackFor (实测一致)

### P0-3: JWT 黑名单 (发现 + 修复真实漏洞)
**漏洞**: `JwtAuthenticationFilter` 完全没有检查 Redis blacklist
- 登出只清本机 session, 旧 token 仍可访问下游 system/search/file

**修复 (commit 225b101)**:
- 增加 `StringRedisTemplate` 依赖 (required=false, 缺 Redis 时降级放行)
- 在 `validateToken` 之前查 `blacklist:<jti>`, 命中即视为未认证
- 不依赖 framework-redis (单向依赖), 避免循环
- 附带修 ADG java-catch-all: `catch (Exception)` → `catch (RuntimeException)`

**端到端验证** (实测):
| 步骤 | 结果 |
| :-- | :-- |
| 1) admin/admin123 登录 | token (jti=93fb225c-...) ✅ |
| 2) GET /system/user/info | 200 ✅ |
| 3) POST /auth/logout | 200 ✅ |
| 4) Redis blacklist:93fb225c-... | true, TTL=86394 (24h) ✅ |
| 5) GET /system/user/info (登出后) | body=`{code:401}`, filter 拒绝 ✅ |
| 6) GET /system/user/info (新 token, control) | 200 ✅ |

## P1 性能弹性

### P1-4: 基准测试 (vs AGENTS.md 基线)
| 场景 | 并发 | 请求 | QPS | p95 | p99 | 状态 |
| :-- | :--: | :--: | :--: | :--: | :--: | :--: |

- ✅ p99 **6x 提升** (165ms vs 1066ms)
- 推论: G1GC + ZGC + 虚拟线程调优后, 业务延迟显著降低

### P1-5: 虚拟线程 Pinning 检测
**结论**: 无 pinning, Spring Boot 4.1 JFR 监控全开
- `spring.threads.virtual.enabled: true` (5 业务模块 + gateway 全配)
- `/management/health/virtualThreadMonitor`:
  - `currentThreadIsVirtual: true`
  - `virtualThreadSupport: true`
  - `pinnedMonitorRunning: true`
  - `pinnedMonitorAvailable: true`
  - peakThreadCount=131, totalStarted=150, live=131
- 1 处 `synchronized` (SentinelConfig.sharedProperties) — DCL 单次 lazy init, 钉住概率极低
- JDK 24+ pinning 显著改善, 实测无 pinned 警告

### P1-6: Feign 超时配置
**结论**: 全链路超时设计完整
- `actuator-config.yaml`: `feign.client.config.default.connectTimeout=3000, readTimeout=10000` (Nacos 同步)
- 5/5 @FeignClient 都有 fallbackFactory
- Gateway `GatewayClientConfig` HttpClient connect=3s
- Redisson `connectTimeout` 已配
- **风险点**: Redisson readTimeout 未显式配 (沿用 Lettuce 默认 60s, 通常够用)
