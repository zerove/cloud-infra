### 4.1 启动命令 (统一)

```bash
# system
java -jar system-module-1.0.0-SNAPSHOT-exec.jar \
  --server.port=8082 --management.server.port=9303 \
  --spring.profiles.active=dev \
  --spring.cloud.nacos.config.server-addr=localhost:8848 \
  --spring.datasource.url=jdbc:postgresql://localhost:5432/cloud_infra \
  --spring.data.redis.host=localhost \
  --auth.jwt.secret=... --auth.internal-call.secret=... \
  -Xms512m -Xmx2g --enable-native-access=ALL-UNNAMED

# auth
AUTH_CAPTCHA_FIXED_CODE=1234 java -jar cloud-infra-auth-1.0.0-SNAPSHOT-exec.jar \
  --server.port=8081 --management.server.port=9302 \
  --spring.profiles.active=dev \
  ...
```
