# Cloud-Infra Development Standard

This project follows the AI-Native Development Standard.

## Core Principles
- Design-First: Design documentation (ADR/Technical Design) must precede implementation.
- Context-Sync: Keep CONTEXT.md and ADRs updated.
- TDD: Tests are the primary specification.
- Self-Correction: Use spec-audit before every commit.
